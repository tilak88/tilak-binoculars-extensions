# Attribution and scope

The baseline idea is based on Hans et al., “Spotting LLMs With Binoculars: Zero-Shot Detection of Machine-Generated Text,” ICML 2024. The public reference implementation is available at <https://github.com/ahans30/Binoculars>.

This repository is not a fork and does not vendor the upstream implementation. The baseline and extension code here is independently organized for reproducibility. Results and feature definitions are derived from the local project notebook and presentations supplied by Tilak Sharma; the original paper remains the authority for the baseline method.

The detector is research software. It must not be represented as a universal or human-supervision-free decision system.
